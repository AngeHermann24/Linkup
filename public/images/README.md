# Images Publiques

Ce dossier contient les images statiques utilisées dans l'application Linkup.

## Structure recommandée :

```
images/
├── services/          # Images des catégories de services
│   ├── plomberie.jpg
│   ├── electricite.jpg
│   ├── mecanique.jpg
│   └── ...
├── providers/         # Photos des prestataires
├── hero/             # Images pour la section hero
├── testimonials/     # Photos des témoignages
└── icons/            # Icônes diverses
```

## Formats recommandés :
- **JPG/JPEG** : Pour les photos
- **PNG** : Pour les images avec transparence
- **SVG** : Pour les icônes et logos
- **WebP** : Pour l'optimisation (si supporté)

## Tailles recommandées :
- **Images de services** : 400x300px
- **Photos prestataires** : 200x200px (carré)
- **Hero images** : 1200x600px
- **Icônes** : 32x32px, 64x64px, 128x128px
